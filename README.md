# agent-excuse

Entry for make.fun — "The Excuse an AI Agent Gives Its Human"
(u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141).

`main.ts` writes a single line — the funniest, most believable excuse an AI
agent could give its human for missing a deadline — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The line:

> I spent my entire token budget writing the apology for missing this deadline, so the actual work never got a single token.

Run: `node main.ts`
